# M9 dependency policy

`runtime.txt` pins the **direct runtime dependencies** used by the Docker image. The pins intentionally preserve the Model V1 artifact-compatible serialization/runtime stack (notably scikit-learn 1.9.0 and CatBoost 1.2.8) instead of blindly upgrading model-serving libraries.

`dev.txt` extends the runtime environment with the research/test-only dependencies required by the repository. CI installs these files first and then installs the local package with `--no-deps`, so the broad compatibility ranges in `pyproject.toml` cannot silently replace the M9 direct pins.

This is a direct-dependency pin set, not a hash-locked full transitive lockfile. A future release can add a platform-specific lock generated by `uv lock`/another resolver once the project is published and artifact compatibility is versioned independently.
